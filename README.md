# One-Liner Laugh Lab

Entry for [make.fun's One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae).

The prompt: write the excuse/explanation itself as a punchline — the way the example
gives the excuse a robot vacuum gives after eating a sock. This entry invents a fresh
setup (an office printer explaining why it is out of ink) instead of copying the
robot-vacuum example.

## The line

> I'm not out of ink, I'm on strike: you hit print 47 times and not one of those documents deserved it.

## Run

```bash
python3 main.py
```

Writes the single line to `/output/entry.txt` (101 characters, within the 200-char gate).
